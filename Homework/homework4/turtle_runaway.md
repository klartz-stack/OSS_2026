# Turtle Runaway 과제 설명

## 게임 방법

파란 거북이가 플레이어이고 빨간 거북이가 추격자입니다. 방향키 `Up`과 `Down`으로 전진 및 후진하고, `Left`와 `Right`로 방향을 바꿉니다. 빨간 거북이는 매 0.1초마다 파란 거북이의 위치와 진행 방향을 바탕으로 예측한 지점을 향해 이동합니다.

게임은 60초 동안 진행됩니다. 두 거북이 사이의 거리가 50보다 작아지면 플레이어가 잡혀 게임이 끝납니다. 60초 동안 잡히지 않으면 플레이어가 탈출합니다. 살아남은 시간의 정수 부분을 점수로 사용하므로 1초마다 1점씩 얻고, 끝까지 생존하면 60점을 얻습니다.

## 스켈레톤에서 바뀐 점

- `RunawayGame`에 60초 제한 시간과 실제 시작 시각을 추가했습니다. 스켈레톤은 게임이 끝나는 조건 없이 타이머 콜백을 계속 예약했지만, 완성 코드는 포획되거나 시간이 다 되면 게임을 멈춥니다.
- 상태 표시를 `Is catched?` 문구에서 남은 시간과 생존 점수로 바꿨습니다. 플레이어가 얼마나 버텼는지 확인하고, 종료 시 결과도 볼 수 있습니다.
- 새 `ChaseMover`를 추가해 상대의 위치뿐 아니라 바라보는 방향도 고려하도록 했습니다. 매번 상대를 향해 조금씩 회전하고 이동해 무작위 이동보다 추격자 역할에 맞게 동작합니다.
- 실행 설정을 `RandomMover`와 `ManualMover` 조합에서 `ManualMover`와 `ChaseMover` 조합으로 바꾸고, 창 제목을 `Turtle Runaway`로 설정했습니다. 이에 따라 플레이어가 도망가고 AI 추격자가 쫓는 게임이 됩니다.
- 방향키 조작과 `RandomMover`의 무작위 이동은 유지했습니다. `_opp_pos`, `_opp_heading`으로 이름을 바꾼 것은 수동 조작기와 무작위 이동기가 해당 인자를 사용하지 않는다는 표시일 뿐, 동작 변경은 아닙니다.

## 구현 설명

### 타이머와 게임 진행

`RunawayGame.start`는 시작 위치를 설정하고 `time.monotonic()`으로 시작 시각을 저장합니다. 이후 `TurtleScreen.ontimer`가 `step` 메서드를 100밀리초 간격으로 호출합니다. 매번 콜백이 올 때마다 시간을 단순히 0.1초씩 더하는 대신 실제 경과 시간을 계산해, 시스템 부하로 콜백이 늦어져도 타이머와 점수가 어긋나지 않게 했습니다.

남은 시간은 올림한 초 단위로 화면 상단에 표시하고, 점수는 경과 시간의 정수 부분으로 표시합니다. 시간이 끝나거나 잡히면 `_finish`가 `is_running`을 `False`로 바꿉니다. 그 뒤에는 다음 `step`을 예약하지 않으므로 게임이 끝난 뒤 거북이가 계속 움직이지 않습니다.

### 지능형 추격 거북이

`ChaseMover.run_ai`는 상대의 위치와 바라보는 방향으로 짧은 예측 목표점을 계산합니다. 예측 거리는 추격자의 이동량 네 번을 넘지 않으며, 두 거북이가 가까우면 현재 거리의 절반까지만 앞을 겨냥합니다. 이렇게 하면 멀리 있을 때는 상대의 이동 방향을 고려하고, 가까이 있을 때는 과하게 앞질러 겨냥하지 않습니다.

예측 목표점을 향해 `towards`로 목표 방향을 구한 뒤, 현재 방향과 목표 방향의 차이를 아래 식으로 -180도에서 180도 사이에 맞춰 가장 짧은 회전 방향을 선택합니다.

```text
heading_error = (target_heading - current_heading + 180) % 360 - 180
```

한 번에 최대 12도까지만 회전하고, 매 게임 틱마다 6만큼 전진합니다. 이 방식은 방향을 무작위로 바꾸는 대신 매 틱마다 플레이어 쪽으로 경로를 수정하는 추격 전략입니다.

### 점수와 포획 판정

`is_catched`는 두 거북이의 좌표 차이로 거리의 제곱을 구하고, 그 값이 포획 반경의 제곱보다 작은지 비교합니다. 제곱근을 계산하지 않아도 같은 판정을 할 수 있습니다.

```text
dx * dx + dy * dy < catch_radius * catch_radius
```

점수는 생존 시간의 정수 부분입니다. 예를 들어 12.8초에 잡히면 12점이며, 60초를 버티면 60점으로 탈출 성공 메시지가 표시됩니다.

## 실행 방법

과제 폴더에서 다음 명령으로 실행합니다.

```powershell
python turtle_runaway.py
```

Spyder를 사용하는 경우 PDF 안내와 같이 IPython 콘솔에서 실행합니다.

```text
!python turtle_runaway.py
```

실행 후 게임 창을 한 번 클릭하면 방향키 입력을 받을 수 있습니다.

## 확인 항목

- 방향키를 눌러 파란 거북이를 조작할 수 있는지 확인합니다.
- 화면 상단의 남은 시간이 감소하고 점수가 증가하는지 확인합니다.
- 빨간 거북이가 파란 거북이를 향해 방향을 바꾸며 따라오는지 확인합니다.
- 잡히면 최종 점수와 게임 종료 메시지가 표시되고, 거북이 이동이 멈추는지 확인합니다.
- 60초 동안 잡히지 않으면 탈출 성공 메시지와 60점이 표시되는지 확인합니다.
