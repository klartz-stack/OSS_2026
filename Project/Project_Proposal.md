# 오픈소스 소프트웨어 텀 프로젝트 주제 구상 22101171 민경준

## 주제

**피싱 이메일 탐지 프로그램** 

## 어떤 프로그램을 목표로 하는지

이메일을 받았을 때 그 메일이 피싱 메일인지 미리 확인해 주는 프로그램

우선은 이메일 파일을 직접 넣으면 내용을 검사하는 방식으로 시작하고, 가능하다면 나중에 Gmail과 연결해서 새 메일을 확인했을때 받은 목록함에서 자동으로 검사하는 기능도 넣는것이 목표입니다.

## 이 주제를 생각한 이유

- 요즘 택배, 은행, 계정 인증 등을 사칭한 메일이 많아서 실제 메일인지 구분하기 어려울 수 있다.
- 메일에 있는 링크를 무심코 누르면 개인정보가 유출될 수 있다.
- 단순히 위험하다고 알려 주는 것뿐만 아니라 **어떤 부분이 수상한지** 같이 보여 주면 도움이 될 것 같다.
- 컴퓨터 보안과도 관련이 있고, Python으로 직접 구현해 볼 수 있을 것 같아 선택했다.

## 생각 중인 기능

- 이메일 제목, 보낸 사람, 본문 가져오기
- 보낸 사람의 이메일 주소가 이상한지 확인하기
- 메일에 포함된 링크가 의심스러운 주소인지 확인하기
- '계정 정지', '즉시 인증', '결제 확인' 같은 특정 문구 찾아보기
- 검사 결과를 `위험 낮음 / 주의 / 위험 높음` 정도로 표시하기
- 왜 위험하다고 판단했는지도 간단히 알려 주기

## 사용할 것 같은 기술

- **Python:** 이메일 내용 분석
- **Streamlit:** 간단한 웹 화면 만들기
- **GitHub:** 코드와 진행 상황 관리
- 악성 URL 검사 API도 필요하면 찾아볼 예정

아직 어떤 라이브러리나 API를 사용할지는 미정

## 대략적인 진행 계획

- **1주 차:** 주제 정하고 필요한 기능 생각하기
- **2주 차:** 이메일 파일 읽고 내용 추출하기
- **3주 차:** 피싱 의심 요소 검사 기능 만들기
- **4주 차:** 화면 만들고 테스트하기
- **5~6주 차:** 부족한 부분 수정, 시간 되면 자동 검사 기능 추가


일단 **이메일 파일을 넣으면 위험 요소를 확인하고 이유를 보여 주는 것**까지 완성하는 것을 1차 목표로 생각하고 있다.
